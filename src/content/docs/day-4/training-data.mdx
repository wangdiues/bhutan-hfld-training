A classifier learns from **training samples**: labelled locations of each land-cover class. The quality of the samples limits the quality of the map. In this exercise you collect samples with the Geometry Tool, prepare them for Random Forest, and train a supervised classification of six classes. Save your script as *Supervised Classification - Random Forest Model* in your own repository.

## Part 1: Set up geometry imports

<Steps>

1. **Create a geometry.** Click the **point** tool at the top left of the map and add points on places that are clearly one class, for example forest.

2. **Set its properties.** Hover over the layer under *Geometry Imports*, click the ⚙️ gear icon, and set:
   - **Name:** the class, for example `forest`;
   - **Import as:** `FeatureCollection`;
   - **Add property:** name `class`, value the class code from the table (Forest = 2);
   - **Colour:** the hex code from the table, so the layers match the map legend.

3. **Add the other classes.** Under *Geometry Imports*, click **+ new layer** and repeat for each class, each with its own `class` value.

4. **Save** the script (Ctrl+S). The geometry layers appear as imports at the top of the script.

</Steps>

<Callout type="mistake" title="Use the property name `class`">
The exercise text names the property `land_class`, but every script that follows reads `class`. If your points carry `land_class`, `sampleRegions` drops the label and training fails. Call it `class`, with a number (not text) as its value.
</Callout>

## Part 3: Collect the samples

You can collect samples with the Geometry Tool, load existing samples from an asset, or both. Assets suit large sample sets collected elsewhere (for example in the field); the Geometry Tool suits a few hundred points and quick updates.

- **Navigate** with the hand tool; scroll to zoom in until you can recognise objects: trees, buildings, roads, field patterns.
- **Switch the basemap** to *Satellite* (top right of the map) and toggle the composite on and off in *Layers* to compare.
- **Place points** only where you are confident of the class, in the middle of a uniform area rather than on edges.
- **Spread them out** across Dzongkhags, elevations and slope directions, not just near roads.
- Collect **at least 10 per class**. More is better.

To combine your drawn points into one collection, and with samples from an asset:

```js
// Your drawn layers, each with a numeric `class` property.
var sample = cropland.merge(forest).merge(grassland)
    .merge(otherland).merge(settlement).merge(wetland);
// Add them to existing samples that already have a numeric `class` (see Part 6, step 4).
var allSamples = samplesMulti.merge(sample);
print('All samples by class', allSamples.aggregate_histogram('class'));
```

## Parts 4 and 5: Sample the covariates and export

Extract the covariate values at each sample point. This turns the image into a table: one row per point, one column per covariate (NDVI, elevation, NDWI…). Remove rows with missing values, then export the table so you don't have to recompute it:

```js
var trainingData = covariates.sampleRegions({
  collection: sample,        // training samples
  properties: ['class'],     // class label
  scale: 10,                 // Sentinel-2 resolution (10 m)
  geometries: true           // keep geometry (optional)
});
trainingData = trainingData.filter(
  ee.Filter.notNull(covariates.bandNames())
);
print("Training Dataset:", trainingData);

Export.table.toAsset({
  collection: trainingData,                    // dataset to export
  description: 'bhutan_training_dataset_2025', // task name
  assetId: 'projects/your_project/bhutan_training_dataset_2025'
});
```

Replace `your_project` with your Cloud project ID.

# Assumes `covariates`, `bands` and `samples_multi` built as in the JavaScript version.
sampled = covariates.sampleRegions(
    collection=samples_multi, properties=["class"], scale=10, geometries=True
).filter(ee.Filter.notNull(bands))
sampled_random = sampled.randomColumn("random", 42)
training = sampled_random.filter(ee.Filter.lt("random", 0.8))
validation = sampled_random.filter(ee.Filter.gte("random", 0.8))

classifier = ee.Classifier.smileRandomForest(numberOfTrees=100, bagFraction=0.7, seed=42).train(
    features=training, classProperty="class", inputProperties=bands
)
matrix = validation.classify(classifier).errorMatrix("class", "classification")
print("Overall accuracy:", matrix.accuracy().getInfo())
classified = covariates.select(bands).classify(classifier).rename("landcover")

## Supervised classification or primitives?

| | Supervised classification (this lesson) | Primitive approach (Day 3, Day 4) |
|---|---|---|
| Models | one model for all classes | one model per class |
| Output | a class per pixel | a probability per class per pixel |
| Combining | the model chooses the most voted class | an assemblage decision tree with your priorities and thresholds |
| Changing a class definition | retrain the model | change the assemblage rules |
| Uncertainty | hidden in the label | kept in the probabilities |

Supervised classification is quicker to set up; the primitive approach gives more control, keeps uncertainty, and makes it easier to put a national forest definition into practice. The course uses primitives for Bhutan's activity data.

<Callout type="bhutan">
Bhutan context: settlements and croplands are small and scattered in narrow valleys, so they need deliberate sampling; forest dominates, so a random set of points would be mostly forest. Aim for balanced numbers per class.
</Callout>

## Key functions

| Function | What it does |
|---|---|
| Geometry Tool: point, + new layer, ⚙️ | Collects labelled points as FeatureCollections |
| `collection.merge(other)` | Combines sample collections |
| `image.sampleRegions({collection, properties, scale})` | Reads covariates at points |
| `ee.Filter.notNull(bandNames)` | Drops samples with missing values |
| `ee.Algorithms.If(...)` | Server-side if/else to recode labels |
| `errorMatrix(actual, predicted)` | Confusion matrix and accuracy |

## Common mistakes

- **Text class values** (`'Forest'`) where a number is needed, or a property name other than `class`.
- **Points on edges** between classes, or on cloud or shadow in the composite.
- **Clustered points.** Samples all near one road teach the model only that road's surroundings.
- **Too few samples for rare classes.** Wetland and settlement need deliberate effort.
