## Part 3: Stratified sampling

`stratifiedSample` draws a simple random sample within each class of a raster. For each value in `classValues`, it takes the number of points given at the same position in `classPoints`. Use your own allocation from the calculator; the exercise used 828 forest, 0 non-forest and 80 deforestation samples.

```python
# Assumes `map_select` (stratification map), `aoi`, scale 30 and projection "EPSG:4326" from Part 1.
remap_select = map_select.remap([2, 10], [1, 3], 2).rename("lc_no")
stratified_sample = remap_select.stratifiedSample(
    numPoints=80, classBand="lc_no", region=aoi, scale=30, projection="EPSG:4326",
    seed=42, classValues=[1, 2, 3], classPoints=[828, 0, 80], geometries=True,
)
print(stratified_sample.aggregate_histogram("lc_no").getInfo())
```

## Part 4: Index the samples

Give each sample a number. Collect Earth Online needs two files:

- **Plots**: points, lines or polygons, each with a unique `plotID`.
- **Samples**: points, each with a `plotID` and a `sampleID`. Several samples may share a `plotID` (a cluster), but within a plot every `sampleID` must be unique.

Here each plot has one sample, so `plotID` and `sampleID` are the same: simple random sampling. The script lists every sample's `system:index` with `aggregate_array`, numbers them from 0 to n − 1 (0 to 907 for 828 + 80 samples; the exercise text said 0 to 1,760), and sets both IDs; `copyProperties` later carries them onto the plots.

## Part 5: Sampling plots

The minimum mapping unit is one pixel of the land-cover map, so the interpreter must judge the land cover of the whole pixel. The map has 30 m pixels, so each sample point becomes a square plot of about one pixel: a 15 m buffer, turned into its bounding box (30 m × 30 m; in EPSG:4326 a 30 m pixel near 27.5° N is slightly narrower east–west, about 27 m).

## Key functions

| Function | What it does |
|---|---|
| `image.remap(from, to, default)` | Recodes classes; anything not listed gets the default |
| `image.stratifiedSample({classBand, classValues, classPoints, region, scale, seed, geometries})` | Random points per class, with a chosen number per class |
| `ee.Dictionary.fromLists(keys, values)` | Maps each sample's system index to a sequential ID |
| `feature.buffer(15).geometry().bounds()` | A square plot around a point |
| `Export.table.toDrive({fileFormat: 'SHP'})` | Shapefile for Collect Earth Online |

## Common mistakes

- **Mismatched `classValues` and `classPoints`**: they are read in pairs.
- **Plots the wrong size** for the map's pixels. Match the plot to the minimum mapping unit.
- **Re-running with a different seed** after interpretation has begun: you get a different sample.
- **Exporting only points.** Collect Earth Online needs both plots and samples, with `plotID` and `sampleID`.

<Callout type="bhutan">
Bhutan context: with 30 m plots on steep slopes, high-resolution imagery can be distorted by relief displacement; interpreters should look at the whole plot and its surroundings, and flag plots they can't interpret rather than guess.
</Callout>
