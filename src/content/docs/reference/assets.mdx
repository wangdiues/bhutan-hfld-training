The course reads two kinds of data:

- **Public catalog datasets**, which anyone with Earth Engine access can load;
- **Project assets** that the trainers and participants created and shared during the training. You can only read these if their owner has shared them with you. If a script stops with "asset not found" or "permission denied", use the last column to make your own.

## Project assets from the training

Paths starting with `…/` are in `projects/bhutan-hfld-readiness-training/assets/`.

| Asset | Holds | Used in | No access? Make your own |
|---|---|---|---|
| `…/Bhutan` | Bhutan's national boundary | most exercises | `ee.FeatureCollection('USDOS/LSIB_SIMPLE/2017').filter(ee.Filter.eq('country_na', 'Bhutan'))`, or upload the official boundary |
| `…/sentinel2Composites/bhutan_s2_<year>_janapr_octdec_int16` | 12-band seasonal Sentinel-2 composite | written by the [Sentinel-2 MRV composite](/bhutan-hfld-training/day-2/sentinel-2-mrv-composite/) export | run [Sentinel-2 MRV composite](/bhutan-hfld-training/day-2/sentinel-2-mrv-composite/) |
| `…/landsatComposite/bhutan_ls89_2025_TashiY` | a participant's 12-band Landsat composite for 2025 | [Calculating covariates](/bhutan-hfld-training/day-3/covariates/), [Forest primitives](/bhutan-hfld-training/day-3/forest-primitives/) | run [Landsat MRV composite](/bhutan-hfld-training/day-2/landsat-mrv-composite/) |
| `…/trainingData/Bhutan_labels_multiclass` | labelled points, six classes (`class_name`) | Forest primitives, training data, embeddings | collect your own ([Collecting training data](/bhutan-hfld-training/day-4/training-data/)) |
| `…/trainingData/Bhutan_stable_classes` | labelled points (`class`) | [Collecting training data](/bhutan-hfld-training/day-4/training-data/) | as above |
| `…/primitives/ls_<Class>_<year>` | course naming for Landsat primitives | [Forest primitives](/bhutan-hfld-training/day-3/forest-primitives/), [Change detection](/bhutan-hfld-training/day-3/change-strata/) | export from Forest primitives |
| `…/GSEdotProd/GSEdotProd_2425` | embedding similarity 2024 vs 2025 | [Determining sample size](/bhutan-hfld-training/day-5/sample-size/) | compute it (Part 3 of that lesson) |
| `…/trainingData/bhutan_hfldTraining_samples_<name>`, `stratifiedPlots_<name>` | reference samples and plots | [Stratified sampling in GEE](/bhutan-hfld-training/day-5/stratified-sampling-gee/) | export your own |
| `projects/servir-mekong/bhutan_primitives/s2_<Class>_2025` | six Sentinel-2 primitives for 2025 | [Assemblage](/bhutan-hfld-training/day-4/assemblage/) | export from Forest primitives, one per class |
| `projects/servir-mekong/bhutan_primitives/s2_2025_janapr_octdec_int16` | Sentinel-2 composite 2025 | [Collecting training data](/bhutan-hfld-training/day-4/training-data/) | run Sentinel-2 MRV composite |
| `projects/servir-mekong/temp/bhutan_ls89_2024_janapr_octdec` | Landsat composite 2024 (used only for its footprint) | [Assemblage](/bhutan-hfld-training/day-4/assemblage/) | use Bhutan's boundary as the area of interest |
| `projects/carbondevelopmentteam/assets/Bhutan/BT002_Bhutan_HFLD/LULC_2024_20250812_epsg4326_10m` | Bhutan land-cover map 2024 | [Determining sample size](/bhutan-hfld-training/day-5/sample-size/) | your own assembled map ([Assemblage](/bhutan-hfld-training/day-4/assemblage/)) |

:::caution[Export paths]
Several scripts export to the training project. Change every `assetId` to a folder in your own Cloud project, for example `projects/<your-project>/assets/hfld/`.
:::

The [script library](/bhutan-hfld-training/reference/script-library/) lists the scripts that use these assets.
