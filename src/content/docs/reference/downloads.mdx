Everything on this page is built from the site's own files each time it is published, so it always matches the lessons. The course has no slide PDFs: every slide is on the lesson pages and in the [slide player](/bhutan-hfld-training/slides/).

## Scripts

<a href="/bhutan-hfld-training/downloads/bhutan-hfld-scripts.zip" download>Download all scripts (zip)</a>: every Earth Engine script in the course, one folder per day, with a README. `.js` files run in the [Earth Engine Code Editor](https://code.earthengine.google.com/); `.py` files are the Python (geemap) versions. Code licence: MIT.

To get a single script, or to open the trainers' original in the Code Editor, use the [script library](/bhutan-hfld-training/reference/script-library/). Many scripts read assets shared with training participants; the [asset catalogue](/bhutan-hfld-training/reference/assets/) shows how to make your own.

## Calculator templates

These CSV files can be pasted into the [accuracy and area estimator](/bhutan-hfld-training/labs/accuracy-area-estimator/). Open one in a spreadsheet, replace the example values with yours, and paste the result into the lab.

| Template | Use it when you have | Columns |
|---|---|---|
| <a href="/bhutan-hfld-training/downloads/confusion-matrix-template.csv" download>Confusion matrix (CSV)</a> | counts of samples by map class and reference class | a corner cell, one column per reference class, `area_ha` (mapped area of each stratum); one row per map class, in the same order. The values are the Day 5 workbook example. |
| <a href="/bhutan-hfld-training/downloads/samples-template.csv" download>One row per sample (CSV)</a> | a Collect Earth Online export joined with your sample | `plotID`, `map` (the stratum), `reference` (the interpreted class). The lab counts them. |

The [sample size calculator](/bhutan-hfld-training/labs/sample-size-calculator/) is filled in on the page; its **Download the results** button saves the allocation as CSV.
